# Cocos Asset Rules

- Every file in `assets/` must have a corresponding `.meta` file with a valid UUID
- Runtime-loaded assets must be placed in `assets/resources/` — nowhere else
- Scene and prefab assets must be placed in `assets/scenes/` and `assets/prefabs/` respectively
- TTF fonts must be used for all Labels (not SystemFont) — SystemFont violates ADR-002 Label batching
- TTF font files must be subset to required characters (numbers + basic Latin) to minimize package size
- Audio clips must be mono, low sample rate (22kHz), and under 50KB each
- Texture assets must use platform-appropriate compression (ETC2 for Android, PVRTC for iOS)
- Package budget is 2MB total for WeChat Mini Game — every asset must justify its size
- Assets that can be procedurally generated (colors, shapes) must NOT be stored as textures — use cc.Graphics
- Asset bundles must be planned before assets are created — main bundle for critical, subpackages for optional
- Levels.json must be in `assets/resources/` for runtime loading via `resources.load()`
- Missing assets must have placeholder files created before the asset is referenced in code
- Asset references in scene files and prefabs must use UUIDs, not file paths
- `assetManager.releaseAsset()` must be called when assets are no longer needed to prevent memory leaks
- The `library/` and `temp/` directories must be gitignored (auto-generated by editor)
