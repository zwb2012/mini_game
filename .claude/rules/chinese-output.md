# 中文文档输出规则

这是为中文开发者定制的规则，面向中国市场（微信小游戏、Android 休闲游戏）。

## 核心规则

1. **所有文档型产物默认使用中文输出。** 包括但不限于：GDD、PRD、技术文档、设计文档、测试报告、验收文档、提审文档、决策记录、阶段产物。

2. **仅在以下情况允许局部保留英文：**
   - 代码（TypeScript、JSON、YAML）
   - API 名称（`GameState`、`EventBus`、`wx.login`）
   - 第三方库名（`Express`、`Cocos Creator`）
   - 字段键名（`project_id`、`stage`）
   - 无法自然翻译的必要英文术语

3. **即使保留英文术语，说明、结论、结构和上下文仍应使用中文。**

4. **如果文档主体不是中文，应视为未通过当前规则。**

5. **Agent 与用户对话时默认使用中文**，除非用户明确使用英文。

## 适用范围
- `design/` 目录下所有设计文档（GDD、UX、美术规范）
- `docs/` 目录下所有技术文档和 ADR
- `production/` 目录下所有项目管理文档
- `templates/` 目录下所有模板文件的正文
- `CLAUDE.md`、`README.md` 等仓库级文档

## 验证标准
以下情况视为通过：
- 标题、说明、结论为中文
- 关键判断、推荐、风险、验收意见为中文
- 英文仅出现在必要技术标识中
