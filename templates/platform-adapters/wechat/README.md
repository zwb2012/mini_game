# 微信小游戏平台适配器模板

这是微信小游戏平台适配器的模板目录，主要承接 **生命周期桥接、广告能力、平台特有能力占位、构建配置** 以及发布准备。

## 目录职责
- `scripts/`：微信小游戏平台相关脚本入口、生命周期桥接脚本、自动化辅助脚本说明
- `config/`：微信小游戏平台配置、环境变量、广告能力配置与构建配置说明
- `docs/`：平台适配约束、接入说明、能力边界、常见问题与补充文档

## 必须覆盖的适配能力
- 生命周期桥接
- 广告能力实现
- 微信平台能力占位
- 微信小游戏构建配置

## 设计原则
- 只保留适配器级别的最小结构，不在这里放具体玩法逻辑
- 所有说明文档优先使用中文
- 与引擎公共能力相关的内容应回到 `contracts/` 或引擎模板中定义

## 使用提示
如果你在这里添加实现，优先确认：
1. 是否属于微信平台特有逻辑
2. 是否可以复用引擎基础模板中的能力
3. 是否需要同步更新控制平面文档
