# Android 平台适配器模板

这是 Android 平台适配器的模板目录，主要承接 Android 侧的接入约定、平台配置与发布准备。

## 目录职责
- `scripts/`：Android 平台相关脚本入口、自动化辅助脚本说明
- `config/`：Android 平台配置、环境变量和构建配置说明
- `docs/`：平台适配约束、接入说明、常见问题与补充文档

## 设计原则
- 只保留适配器级别的最小结构，不在这里放具体玩法逻辑
- 所有说明文档优先使用中文
- 与引擎公共能力相关的内容应回到 `contracts/` 或引擎模板中定义

## 使用提示
如果你在这里添加实现，优先确认：
1. 是否属于 Android 平台特有逻辑
2. 是否可以复用引擎基础模板中的能力
3. 是否需要同步更新控制平面文档
