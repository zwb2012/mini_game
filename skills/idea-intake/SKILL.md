# Idea Intake

## Overview
Convert a vague game idea into a compact project card. The output must be comparable across many ideas, not a free-form brainstorm.

## When to Use
- A new idea just appeared
- The concept is still fuzzy
- The portfolio needs comparable inputs

## Required Fields
- Project name
- One-sentence gameplay loop
- Target audience
- Core hook
- Ad fit
- Main risks
- Recommended next state

## Workflow
1. Rewrite the idea into one sentence.
2. Name the likely audience.
3. Identify the strongest replay or curiosity hook.
4. Describe how ads could fit without defining placements yet.
5. Name the main execution risk.
6. End with `candidate` or `hold`.

## Output
Write `project-card.md` using the template fields only.

## Common Mistakes
- Expanding scope with extra modes
- Mixing evaluation into intake
- Leaving the next state undefined
