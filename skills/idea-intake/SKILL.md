# Idea Intake

## Overview
把一个模糊的小游戏想法压缩成可比较、可进入后续评估流程的项目卡。输出必须稳定、可复用，不能只是自由发挥的创意描述。

## When to Use
- 出现了一个新的小游戏方向
- 概念还比较模糊
- 需要把多个方向放进统一候选池比较

## Required Fields
- name
- one_sentence_loop
- target_audience
- core_hook
- ad_fit_summary
- primary_risk
- recommended_next_state

## Workflow
1. 用一句话重写玩法主循环。
2. 明确目标用户是谁。
3. 提炼最强的爽点、传播点或好奇钩子。
4. 简述广告如何自然融入，而不是提前设计广告位。
5. 说明主要风险。
6. 给出 `candidate` 或 `hold` 作为推荐下一状态。
7. 正文说明默认使用中文。

## Output
只按 `project-card.md` 模板输出，不额外扩写。

## Common Mistakes
- 为了显得完整而提前扩范围
- 在 intake 阶段就混入大量评估结论
- 不写清楚下一状态
- 主要内容用英文表达
