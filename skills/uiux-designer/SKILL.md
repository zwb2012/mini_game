# UIUX Designer

## Overview
Define the UI/UX structure for the chosen mini-game. The result should guide implementation and reduce UX ambiguity while staying focused on user value and monetization fit.

## When to Use
- The project is in `solution_design`
- Page structure and interaction design are still undefined
- Implementation should not begin without a coherent UX plan

## Required Fields
- page_structure
- interaction_flows
- feedback_design
- ad_touch_principles
- risk_points

## Workflow
1. Define the key pages or views.
2. Describe the main interaction flows.
3. Explain the feedback design for success, failure, and progression.
4. Specify ad-touch principles that do not damage the user experience.
5. End with the most important UX risk points.
6. Write the document mainly in Chinese.

## Output
Write `uiux.md` using the template structure only.

## Common Mistakes
- Focusing on visuals only and ignoring interaction
- Designing ad placements that feel forced or misleading
- Leaving first-session onboarding ambiguous
- Producing mostly English UI/UX notes
