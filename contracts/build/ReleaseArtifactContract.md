# 发布产物契约

## 目标
定义发布产物的引擎无关契约，统一描述可交付、可校验、可追踪的构建输出。

## 必须提供的能力
- 提供产物身份标识。
- 提供平台目标信息。
- 提供版本号、构建号与来源信息描述。
- 提供产物清单与文件清单描述。
- 提供 readiness 标记。
- 提供校验和、签名或等价校验信息描述。
- 提供回滚与追踪所需的最小元数据。

## 输入
- 构建目标信息。
- 产物文件列表。
- 版本元数据。
- 校验元数据。

## 输出
- 发布产物描述。
- 平台目标。
- readiness 结果。
- 产物完整性信息。
- 可追踪的版本标识。

## 禁止事项
- 不得要求某个引擎产物目录结构必须固定。
- 不得把发布流程中的人工步骤写成运行时依赖。
- 不得在契约中包含部署平台专属操作命令。
