# 构建目标契约

## 目标
定义构建目标的引擎无关契约，用于描述不同平台、不同渠道与不同运行模式的构建要求。

## 必须提供的能力
- 提供目标标识与目标平台描述。
- 提供引擎版本描述。
- 提供适配器绑定描述。
- 提供开发、测试、预发与正式构建模式描述。
- 提供资源裁剪、特性开关与包体约束描述。
- 提供输出路径描述。
- 提供构建目标可验证的约束集合。

## 输入
- 目标标识。
- 平台标识。
- 渠道标识。
- 构建模式。
- 引擎版本。
- 适配器绑定信息。
- 包体、资源与特性约束。
- 输出路径。

## 输出
- 目标构建配置。
- 约束校验结果。
- 输出路径。
- 不满足条件时的错误列表。

## 禁止事项
- 不得绑定到任何特定引擎的构建命令。
- 不得把打包脚本细节放进契约正文。
- 不得让运行时逻辑依赖构建工具内部实现。
