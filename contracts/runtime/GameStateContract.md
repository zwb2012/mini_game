# 游戏状态契约

## 目标
定义游戏运行状态的引擎无关契约，统一描述局内状态、全局状态、阶段状态与恢复状态。

## 必须提供的能力
- 提供状态读取、写入与重置能力。
- 提供只读查询面给外部使用。
- 提供状态变更通知能力。
- 提供状态快照与恢复能力。
- 提供按域隔离的状态访问能力。

## 输入
- 状态键或状态域。
- 状态值。
- 状态变更原因。
- 快照与恢复参数。

## 输出
- 当前状态值。
- 状态变更结果。
- 状态快照。
- 恢复结果。
- 只读查询结果。

## 禁止事项
- 不得把状态存储实现绑定到某个引擎。
- 不得在契约中塞入具体关卡逻辑。
- 不得让任意 UI 直接修改内部状态而不经过契约。
- 不得让外部调用方绕过契约直接改内部状态容器。
