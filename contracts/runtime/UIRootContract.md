# UI 根契约

## 目标
定义 UI 组织与挂载的引擎无关契约，为界面层提供统一的根节点、分层与显示控制方式。

## 必须提供的能力
- 提供 UI 挂载根与层级管理能力。
- 提供弹窗、遮罩、提示与常驻界面的容器能力。
- 提供 UI 显隐、层级切换与布局刷新能力。
- 提供界面销毁或回收的统一入口。

## 输入
- UI 组件或视图标识。
- 显示层级与挂载层参数。
- 显隐控制参数。
- 生命周期钩子。

## 输出
- UI 挂载结果。
- 当前层级状态。
- 界面显示或隐藏结果。

## 禁止事项
- 不得依赖某个引擎的节点树 API。
- 不得在契约中包含具体布局样式实现。
- 不得把页面导航规则写成 UI 细节。
