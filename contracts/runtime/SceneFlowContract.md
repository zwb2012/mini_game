# 场景流契约

## 目标
定义场景切换与场景编排的引擎无关契约，统一管理进入、退出、切换与场景级数据传递。

## 必须提供的能力
- 提供进入场景、退出场景与切换场景的能力。
- 提供场景加载完成、失败与取消的结果通知。
- 提供场景参数传递能力。
- 提供场景级别的可恢复状态承载能力。

## 输入
- 目标场景标识。
- 场景参数。
- 过渡策略。
- 加载与失败回调。

## 输出
- 场景切换结果。
- 当前激活场景标识。
- 场景生命周期事件。

## 禁止事项
- 不得绑定到某个引擎的场景树实现。
- 不得把业务状态和场景导航逻辑强耦合。
- 不得要求调用方直接管理底层资源加载细节。
