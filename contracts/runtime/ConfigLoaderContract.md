# 配置加载契约

## 目标
定义配置读取与解析的引擎无关契约，统一管理环境配置、目标端配置、功能开关与运行时覆盖项。

## 必须提供的能力
- 提供环境配置加载能力。
- 提供目标端配置加载能力。
- 提供功能开关加载能力。
- 提供按键、按域或按版本读取配置的能力。
- 提供默认值与覆盖值的合并能力。
- 提供配置缺失时的 fail-fast 反馈。

## 输入
- 配置源标识。
- 配置键或配置域。
- 默认值。
- 刷新与缓存参数。

## 输出
- 解析后的配置值。
- 配置版本信息。
- 加载失败原因。
- 是否命中缓存的标记。

## 禁止事项
- 不得绑定到某个引擎的资源加载 API。
- 不得把远程拉取协议写入业务契约。
- 不得把配置格式限制为单一引擎专属格式。
- 不得在缺少必需配置时静默继续运行。
