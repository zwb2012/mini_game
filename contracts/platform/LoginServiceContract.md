# 登录服务契约

## 目标
定义用户登录能力的引擎无关契约，为账号识别、会话建立与登录态恢复提供统一入口。

## 必须提供的能力
- 提供发起登录、退出登录与查询登录态的能力。
- 提供匿名或游客态启动能力。
- 提供已登录态与匿名态之间的切换能力。
- 提供平台身份令牌的标准化能力。
- 提供登录失败、取消与超时的结果回调。

## 输入
- 登录方式标识。
- 授权参数。
- 当前会话上下文。
- 登录回调与失败处理。

## 输出
- 登录状态。
- 用户身份信息。
- 标准化后的身份令牌或等价凭据。
- 登录失败原因。

## 禁止事项
- 不得绑定到特定平台的账号体系细节。
- 不得把凭据存储策略写入契约。
- 不得假定登录流程一定包含某个引擎 UI。
- 不得把平台原始 token 直接泄露给业务层而不做规范化。
