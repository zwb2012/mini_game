# 广告服务契约

## 目标
定义广告能力的引擎无关契约，让运行时只依赖统一的广告入口，而不关心底层广告供应商或 SDK。

## 必须提供的能力
- 提供广告位的可用性查询能力。
- 提供展示广告、关闭广告、预加载广告的能力。
- 提供广告成功、失败、取消、超时等结果回调。
- 提供基础降级能力，确保广告不可用时业务仍可继续。

## 输入
- 广告位标识。
- 展示场景标识。
- 预加载或展示请求参数。
- 结果回调与错误回调。

## 输出
- 广告是否可用。
- 广告展示结果。
- 广告失败原因与错误信息。
- 可供上层决策使用的回调事件。

## 禁止事项
- 不得绑定任何特定引擎或特定广告平台的 API。
- 不得把广告 UI 样式、文案和投放策略写死在契约中。
- 不得要求调用方理解底层 SDK 生命周期。
