# 广告服务契约

## 目标
定义广告能力的引擎无关契约，让运行时只依赖统一的广告入口，而不关心底层广告供应商、平台 SDK 或具体引擎。

## 必须提供的能力
- 提供激励视频请求与激励视频结果回调能力。
- 提供插屏广告请求与插屏展示结果能力。
- 提供广告位可用性查询能力。
- 提供广告成功、失败、取消、超时等统一结果回调能力。
- 提供广告不可用时的基础降级能力，确保游戏流程可继续。

## 输入
- 广告位标识。
- 展示场景标识。
- 激励视频或插屏请求参数。
- 结果回调与错误回调。

## 输出
- 广告是否可用。
- 广告展示结果。
- 广告失败原因与错误信息。
- 可供上层决策使用的回调事件。

## 禁止事项
- 不得绑定任何特定引擎或特定广告平台的 API。
- 不得把广告 UI 样式、文案和投放策略写死在契约中。
- 不得要求调用方理解底层 SDK 生命周期。
- 不得把具体游戏玩法逻辑塞进广告契约。
