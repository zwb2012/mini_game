# 变现事件契约

## 目标
定义变现类埋点的引擎无关契约，用于描述广告、支付、订阅与收益相关事件。

## 必须提供的能力
- 提供广告请求事件。
- 提供广告成功、失败与取消事件。
- 提供激励奖励发放事件。
- 提供支付占位事件表达。
- 提供订单、广告位、商品与渠道上下文能力。
- 提供收入结果、转化结果与失败原因能力。

## 输入
- 变现事件名称。
- 订单、商品或广告位标识。
- 金额、币种或等价收益属性。
- 渠道与会话上下文。

## 输出
- 标准化后的变现事件。
- 上报结果与失败原因。
- 可用于对账和分析的元数据。

## 禁止事项
- 不得直接绑定任何广告平台或支付平台字段。
- 不得记录不必要的支付敏感信息。
- 不得把收益归因规则写成引擎专属实现。
- 不得遗漏广告请求、成功、失败与奖励发放这些关键状态。
