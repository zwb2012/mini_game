# 游戏玩法事件契约

## 目标
定义玩法类埋点的引擎无关契约，用于描述核心操作、阶段变化与关键结果。

## 必须提供的能力
- 提供会话开始事件。
- 提供会话结束事件。
- 提供失败、重试、复活等关键结果事件。
- 提供玩法事件命名与分类规则。
- 提供事件属性字段的统一结构。
- 提供会话、关卡、局内状态等上下文字段。

## 输入
- 事件名称。
- 事件属性。
- 玩法上下文。
- 采样与脱敏要求。

## 输出
- 标准化后的玩法事件。
- 采集结果或失败原因。
- 可用于分析的最小上下文。

## 禁止事项
- 不得把某个引擎的回调名称直接当作事件契约。
- 不得把 UI 交互细节混进玩法语义。
- 不得记录超出分析需要的敏感信息。
- 不得把广告或支付语义混入玩法事件契约。
