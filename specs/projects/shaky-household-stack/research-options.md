# 项目
- 名称：摇晃桌面叠物
- 标识：shaky-household-stack

# 调研范围
- 目标题材：轻度搞笑 + 平衡堆叠 + 失败反差
- 目标人群：碎片化时间中的轻度休闲玩家、偏短会话微信用户
- 竞品样本：堆叠类、平衡类、物理失误类小游戏

# 候选方向
## 候选 1
- 方向名称：家居杂物平衡塔
- 一句话概念：玩家在不断晃动的桌面上叠放锅碗瓢盆、台灯、闹钟等杂物，尽量撑到倒塌前拿更高分。
- 吸引力判断：直观易懂，失败画面有喜剧效果，适合短局循环。
- 广告变现适配：适合在复活、结算加倍、解锁特殊道具时接激励视频。
- 主要风险：若物体差异不明显，后期容易变成重复堆叠。

## 候选 2
- 方向名称：危险早餐桌
- 一句话概念：玩家在早餐桌上叠放牛奶、面包机、鸡蛋和果酱，桌面会逐渐倾斜并制造连锁失误。
- 吸引力判断：主题统一，视觉记忆点较好，但内容延展性略弱。
- 广告变现适配：可在失败后提供“稳定桌面 3 秒”类激励复活。
- 主要风险：单一主题可能较快耗尽新鲜感。

## 候选 3
- 方向名称：离谱搬家挑战
- 一句话概念：玩家把冰箱、台扇、植物、纸箱等离谱家居物件堆到小推车上，挑战不翻车。
- 吸引力判断：题材更夸张，传播感更强，但操作反馈需要更细致。
- 广告变现适配：适合结算翻倍、特殊物件试玩和主题包解锁。
- 主要风险：如果物理反馈做不好，会从搞笑变成纯失控。

# 推荐排序
- 第一推荐：家居杂物平衡塔
- 第二推荐：离谱搬家挑战
- 第三推荐：危险早餐桌

# 决策建议
- 推荐进入立项的方向：家居杂物平衡塔
- 推荐原因：概念最直观、失败反馈最容易形成短视频传播点、广告接入位置自然，且开发成本比“离谱搬家挑战”更可控。
