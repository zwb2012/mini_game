# 项目
- 名称：摇晃桌面叠物
- 标识：shaky-household-stack

# 页面结构
- 页面 1：开始页（开始按钮、简短玩法提示）
- 页面 2：主游戏页（桌面、待放置物体、分数、当前层数）
- 页面 3：结算页（分数、复活、结算加倍、再来一局）

# 交互流程
- 流程 1：进入开始页 → 点击开始 → 进入主游戏 → 连续放置物体 → 倒塌后进入结算页
- 流程 2：结算页失败后 → 选择复活 → 回到主游戏继续一轮；或选择再来一局重开

# 视觉与反馈
- 主要风格：夸张但简洁的家居杂物卡通风格
- 反馈机制：放置成功有轻微弹性反馈，摇晃加剧时有抖动提示，倒塌时有明显音效与散落动画
- 广告触点原则：广告只出现在结算页与复活节点，不嵌进主操作链路

# 风险
- 易误触点：若复活按钮与其他按钮过近，容易造成误触
- 易流失点：若开始页教程过长或局内反馈不清晰，新玩家可能在首局直接流失
