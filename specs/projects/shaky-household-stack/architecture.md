# 项目
- 名称：摇晃桌面叠物
- 标识：shaky-household-stack

# 架构目标
- 目标：在微信小游戏环境中提供稳定、可调、可扩展的单局物理堆叠体验
- 关键约束：包体要轻、首局加载快、物理更新简单稳定、广告和埋点不能打断主循环

# 模块划分
- 模块 1：局内核心循环模块（物体生成、放置、结算）
- 模块 2：物理与重心控制模块（桌面摇晃、重力、碰撞与倒塌判定）
- 模块 3：商业化与数据模块（广告触点、埋点、局后结果记录）

# 数据与状态流
- 关键状态：待放置、放置中、稳定中、失控中、结算中
- 数据来源：局内分数、层数、放置次数、复活次数、广告触发结果
- 流转说明：开始新局后生成待放置物体；放置完成后进入稳定检测；一旦触发失稳阈值则转入失控与结算；结算后进入再来一局或复活分支

# 技术决策
- 决策 1：采用简化的 2D 物理判定与可调参数，而不是高精度复杂物理
- 决策 2：局内状态机与商业化模块解耦，避免广告逻辑污染主玩法
- 依赖项：微信小游戏基础能力、轻量音效资源、埋点与广告接口封装

# 风险
- 技术风险：物理判定过于敏感时，玩家会觉得操作不公平
- 性能风险：同时出现过多动态物体时，低端机可能出现掉帧
