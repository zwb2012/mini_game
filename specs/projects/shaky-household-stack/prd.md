# 项目
- 名称：摇晃桌面叠物
- 标识：shaky-household-stack

# 产品目标
- 目标用户：喜欢短时、轻操作、容易失败但愿意重复来一局的轻度休闲玩家
- 核心体验假设：玩家会因为“马上就要倒了”的紧张感和杂物倒塌的搞笑反馈反复开始下一局
- 商业目标：通过短局复玩、失败复活和结算加倍形成广告观看闭环

# 核心玩法
- 核心循环：选择物体 → 放置到摇晃桌面 → 调整重心避免倒塌 → 倒塌后结算分数并决定是否复活/再来一局
- 单局目标：在倒塌前叠出更高层数和更高分数
- 失败条件：任意关键物体滑落并引发整体倒塌，或重心失控导致桌面物体散落到阈值以下

# 范围定义
- 必做范围：单一主模式、基础物理堆叠、分数结算、复活、结算加倍、基础埋点、基础音效反馈
- 延后范围：主题桌面、特殊道具、大量物件包、排行榜社交扩展、复杂成长系统
- 不做范围：多人模式、剧情模式、重内容任务系统

# 验收标准
- 标准 1：新玩家在首局 10 秒内能理解“把物体叠稳别倒”的目标
- 标准 2：单局失败后，玩家有自然动力选择复活或再来一局
- 标准 3：广告触点不会强行打断放置动作本身，只出现在复活、结算等自然节点

# 风险与备注
- 主要风险：如果物体物理特性差异不明显，玩家会觉得只是重复堆叠，没有持续新鲜感
- 备注：后续架构与 UI/UX 需要优先保证“失败反馈有趣但不混乱”，而不是盲目增加物件数量
