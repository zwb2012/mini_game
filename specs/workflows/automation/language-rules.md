# 中文输出规则

## 目标
确保自动化模板设计文档，以及自动化流水线中生成的文档型产物，默认都以中文为主输出，方便直接审阅、沉淀和复用。

## 规则
1. 所有研究、PRD、架构、方案、UI/UX、测试、验收、上架准备文档默认使用中文。
2. 仅在以下情况允许局部保留英文：
   - 代码
   - API 名称
   - 第三方库名
   - 字段键名
   - 无法自然翻译的必要英文术语
3. 即使保留英文术语，说明、结论、结构和上下文仍应使用中文。
4. 若模板中包含 frontmatter，可使用英文键名，但正文说明必须以中文撰写。
5. 若自动生成结果主要为英文，应视为未通过语言规则，需要重写或回退。

## 适用范围
- 模板仓库中的设计文档
- 模板仓库中的阶段模板
- 项目仓库中的阶段产物
- 组合层中的管理文档

## 验证标准
以下情况视为通过：
- 标题、说明、结论为中文
- 关键判断、推荐、风险、验收意见为中文
- 英文仅出现在必要技术标识中
